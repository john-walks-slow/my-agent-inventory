🏷️ Badge 优化设计方案对比：强化“可点击进入”交互感知

均已搭配精修版像素鲸鱼 · 480×160 原尺寸实机渲染

方案 0: 当前基准版 (Baseline)
现状：传统静态名片，无任何可点击或交互线索，容易被误认为纯统计卡片
方案 A: 右上角交互胶囊 (Action Pill ↗) [推荐]
现代 Web & GitHub 卡片主流习惯：右上角醒目外链胶囊 [ 🎒 查看背包 ↗ ]，最明确直观
方案 B: 右下角实体立体按键 (Action Button ➔)
星露谷实体感：右下角设计一块带下沉厚度的像素木质/石质按键 [ ▶ 进入背包 ➔ ]，诱人点击
方案 C: 像素小手光标指引 (Pixel Hand Cursor)
复古游戏机感：右下角像素手套光标指引 [ CLICK TO OPEN ↗ ]，唤醒游戏操作本能
方案 D: 右上角折角探索缎带 (Corner Ribbon)
典藏卡牌感：右上角 45° 像素红丝带 [ OPEN ↗ ]，精致复古，兼顾轻盈与辨识度

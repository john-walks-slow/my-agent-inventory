## 一、验证环境与地址
- 本地服务地址：`http://127.0.0.1:5180`
- 局域网访问地址：`http://192.168.71.34:5180`（支持手机/平板直连体验）

---

## 二、核心验收场景清单

### 1. 视觉与像素风格体验
- **步骤**：在浏览器打开上述地址。
- **预期**：
  - 呈现充满质感的星露谷暖木色大面板（带有复古像素边框与阴影）；
  - 顶部显示 4 个父分类 Tab：`DSH 插件 (8)`、`Agent 技能 (6)`、`MCP 服务器 (3)`、`实战秘籍 (4)`；
  - 字体为清晰细腻的像素点阵风格；
  - 左侧为经典 36 格（3行×12列）凹陷背包槽位，物品右上/右下角带有品质星级（银/金/铱星）与堆叠数字。

### 2. 背包物品交互与详情面板
- **步骤**：
  1. 鼠标悬停在不同物品上，聆听轻微的木质敲击音效（或浮层提示）；
  2. 点击任意物品（如 `dsh-wait-subagent` 或 `container-ops`）；
  3. 查看右侧详情面板，点击“复制命令”按钮；
  4. 点击“阅读关联秘籍”按钮。
- **预期**：
  - 点击物品发出清脆的选取音效，槽位高亮为星露谷红色选框；
  - 右侧呈现完备的痛点分析、核心亮点、深度解析与配置示例；
  - 点击“复制命令”触发清脆金币音效，文字变为“已复制！”且剪贴板成功获取指令；
  - 点击“阅读关联秘籍”平滑自动切换到 Books 阅览器并定位到该文章。

### 3. 子分类与实时搜索筛选
- **步骤**：
  1. 点击子类别胶囊按钮（如“核心基石”、“环境运维”）；
  2. 在搜索框输入关键字（如 `tunnel` 或 `进程`）。
- **预期**：
  - 36 格背包迅速联动重排，仅保留匹配物品，其余格子保留凹陷空槽状态；
  - 底部实时统计已收纳装备数。

### 4. Books 典籍与羊皮纸阅读体验
- **步骤**：切换到“实战秘籍 (Books)”标签页，在左侧书架挑选《孤儿 Vite 进程霸占 80% CPU 的排查与优雅杀死规范》。
- **预期**：
  - 触发逼真的纸张翻动沙沙白噪声音效；
  - 右侧展现淡黄色做旧羊皮纸纹理与暗褐色排版；
  - Markdown 标题、列表、引用与黑曜石终端代码高亮块渲染优雅自然；
  - 文本可随意选中、复制。

### 5. 沉浸式彩蛋互动
- **步骤**：
  1. 点击顶部 HUD 的金币计数器（`77,777g`）；
  2. 点击音效开关按钮；
  3. 点击“农场主档案”按钮。
- **预期**：
  - 每次点击金币产生丰收清脆声，余额递增；
  - 可静音/恢复音效；
  - 弹出复古像素“农场主 John Ren”详细硬件环境与战绩面板，可正常关闭。
